# Attendance Tracker

A lightweight browser-based attendance tracker for tracking student attendance statuses such as Present, Late, Absent, and Excused.

## Features
- Add students to the list
- Mark attendance status with one click
- See live summary counts
- Data persists in the browser using local storage
- Reset all data when needed

## Run it locally
Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
cd C:/Users/Lenovo/Documents/attendance-tracker
python -m http.server 8000
```

Then visit `http://localhost:8000`.
